## 🧐 About <a name = "about"></a>

WAZTE is an online platform designed to foster responsible waste management and enhance sustainability. WAZTE facilitates the correct disposal of recyclable items by assisting individuals in locating recycling centers, accessing current collection schedules, and connecting with local facilitators.
